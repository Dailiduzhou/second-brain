# 前缀和与差分

前缀和把区间查询降到 $O(1)$，差分把区间修改降到 $O(1)$，代价分别是额外的 $O(n)$ 空间和最后的一次还原。两者互为逆运算，边界下标都落在 `l - 1` 与 `r + 1` 上。入口见 [[Index Page#算法]]。

> [!important] 互为逆运算
> 前缀和的差得到元素，差分的和还原数组：`pre[i] - pre[i - 1] = a[i]`，`a[i] = a[i - 1] + d[i]`。**前缀和查区间，差分改区间，两者都必须注意偏移一位的边界下标。**

| 需求 | 结构 | 预处理 | 单次操作 |
| --- | --- | --- | --- |
| 多次查询区间和 | 前缀和 | $O(n)$ | $O(1)$ 查询 |
| 多次修改区间、最后统一读取 | 差分 | $O(n)$ | $O(1)$ 修改 |

以下代码约定 1-based 下标且 `a[0] = pre[0] = 0`。因此差分数组要开到 `n + 2`，因为修改 `[l, n]` 时会写入 `d[n + 1]`。

## 一、前缀和：用一次预处理换 $O(1)$ 区间查询

### 构造

```cpp
// a 为 1-based，a[0] = 0。前缀和可能超过 int，区间和较大时用 long long。
vector<long long> pre(n + 1, 0);
for (int i = 1; i <= n; ++i)
    pre[i] = pre[i - 1] + a[i];
```

### 区间和

`[l, r]` 的区间和是 `pre[r] - pre[l - 1]`。减掉的是 `l - 1` 而不是 `l`：

- `pre[r]` 覆盖 `[1, r]`；
- `pre[l - 1]` 覆盖 `[1, l - 1]`；
- 相减后剩下 `[l, r]`。

`pre[l] - pre[l - 1]` 的结果只是 `a[l]`，不是区间和。用前缀和数组自身取单点值也遵循同一关系：`a[i] = pre[i] - pre[i - 1]`。

> [!warning] 负下标
> `l = 1` 时会访问 `pre[0]`，这正是把数组开到 `n + 1` 并把 `pre[0]` 初始化为 0 的原因。写成 `pre[l] - pre[l - 1]` 在 `l = 1` 时不会报错，只会静默给出错误答案。

### 二维前缀和

`sum[i][j]` 表示 `(1, 1)` 到 `(i, j)` 的矩形和，用容斥构造：

$$
sum[i][j] = a[i][j] + sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]
$$

```cpp
vector<vector<long long>> sum(n + 1, vector<long long>(m + 1, 0));
for (int i = 1; i <= n; ++i)
    for (int j = 1; j <= m; ++j)
        sum[i][j] = a[i][j] + sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1];
```

查询以 `(x1, y1)`、`(x2, y2)` 为角点的矩形：

```cpp
long long rect = sum[x2][y2] - sum[x1 - 1][y2] - sum[x2][y1 - 1] + sum[x1 - 1][y1 - 1];
```

减去的两块矩形在 `(x1 - 1, y1 - 1)` 处重叠，被减了两次，所以要把 `sum[x1 - 1][y1 - 1]` 加回来。

[数列前缀和 4（B3693）](https://www.luogu.com.cn/problem/B3693) 是二维前缀和的典型应用：询问数达 $10^6$，且要求结果对 $2^{64}$ 取模。C++ 的无符号整数溢出按 $2^{64}$ 取模，是定义良好的行为，因此用 `unsigned long long` 存前缀和即可省掉每次取模的开销。

## 二、差分：把区间修改摊到一次还原

### 构造

```cpp
// 需要 n + 2 个位置，因为会写 d[r + 1]，r 可能等于 n。
vector<int> d(n + 2, 0);
for (int i = 1; i <= n; ++i)
    d[i] = a[i] - a[i - 1];
```

### 区间加

对 `[l, r]` 统一加 `x`：

```cpp
d[l] += x;
d[r + 1] -= x;
```

`d` 的前缀和恰好表示「每个位置累计被改动了多少」：`d[l]` 让影响从 `l` 开始生效，`d[r + 1]` 在 `r` 之后把它抵消掉。抵消位置必须是 `r + 1`，写成 `d[r] -= x` 会使区间右端点提前一位。

### 还原

```cpp
vector<int> a(n + 1, 0);
for (int i = 1; i <= n; ++i)
    a[i] = a[i - 1] + d[i];
```

还原依赖 `a[0] = 0` 作为初值。差分数组本身也是完整的表示：如果所有修改都是区间加，可以只维护 `d`，在最后统一前缀和一次。

> [!warning] 差分的适用边界
> 差分让每次修改变成 $O(1)$，但读取任意元素需要一次 $O(n)$ 的前缀和。**修改与查询交替出现时，总代价仍是 $O(nq)$**，这种场景应换成树状数组或线段树。差分适合「批量修改 + 最后一次查询」，而不是通用的动态区间结构。

## 三、同余：前缀和只用来定位，不用来取值

区间和的性质可以绕过前缀和的具体数值，只用它的余数：

$$
\text{sum}(l, r) \equiv 0 \pmod{k} \iff pre[r] \equiv pre[l-1] \pmod{k}
$$

因为 `sum(l, r) = pre[r] - pre[l-1]`，两个前缀和对 `k` 同余等价于差是 `k` 的倍数。

### 最长子段和能被 7 整除（P3131）

求最长区间使区间和能被 7 整除。由上式，只需要知道每个余数**首次出现的位置**，之后每遇到同一余数就能算出一段最长区间：

```cpp
// pre[i] 为前 i 项和，pre[0] = 0。
vector<int> first(7, -1);
first[0] = 0;                    // 空前缀，余数 0 最早出现在位置 0
int ans = 0;
for (int i = 1; i <= n; ++i) {
    int r = pre[i] % 7;
    if (first[r] == -1) first[r] = i;
    else ans = max(ans, i - first[r]);   // 区间是 (first[r], i]
}
```

这里不需要存储前缀和的值，只需要「余数 → 首次位置」的映射；区间长度是 `i - first[r]`，因为差值对应的是下标 `first[r] + 1` 到 `i`。`first[0] = 0` 不能省，否则整段前缀本身就能被整除的情况会被漏掉。

### 统计 k 倍区间个数

如果问的是个数而不是最长长度，就必须统计同余前缀的数量，并计入 `pre[0]`：

```cpp
vector<long long> cnt(k, 0);
cnt[0] = 1;                      // 先放入空前缀，否则漏掉从下标 1 开始的区间
long long ans = 0;
for (int i = 1; i <= n; ++i)
    ans += cnt[pre[i] % k]++;    // 与之前每个同余前缀各构成一个区间
```

`a` 中可能存在负数，此时 C++ 的 `%` 会保留被除数符号，余数落在 `(-k, k)`。需要先规整到 `[0, k)`：

```cpp
int r = ((pre[i] % k) + k) % k;
```

## 四、组合用法：差分累加 + 两层前缀和

[Karen and Coffee（CF 816B）](https://codeforces.com/problemset/problem/816/B) 同时需要两个方向：用差分统计「每个温度被多少个食谱覆盖」，再用前缀和回答「某温度区间内有多少温度被至少 `k` 个食谱覆盖」。

```cpp
// d 是覆盖次数的差分数组，温度范围为 [1, MAXT]。
vector<int> cover(MAXT + 2, 0), good(MAXT + 2, 0);
for (int t = 1; t <= MAXT; ++t) {
    cover[t] = cover[t - 1] + d[t];              // 第一层：还原每个温度的推荐数
    good[t] = good[t - 1] + (cover[t] >= k);     // 第二层：统计达标温度的前缀个数
}
// 查询 [a, b]：good[b] - good[a - 1]
```

> [!important] 两层前缀和的含义不同
> 第一层前缀和还原的是「这个温度有多少个推荐」，第二层前缀和回答的是「不超过 `t` 的温度里有几个达标」。两者不能合并成一个数组，因为第二层的被累加对象是布尔判定而不是原始数值。

## 五、值域轴上的差分与后缀和

前面的前缀和与差分都建在下标轴 `a[1..n]` 上。把同一套操作搬到**值域轴**后，数组下标不再是元素序号，而是可能的取值；砍树（P1873）是这一转换的标准例子。

### 应用：砍树（P1873）

给定 `n` 棵树的高度，求最大的整数锯片高度 `H`，使 `f(H) = Σ max(0, h_i - H) ≥ M`。

`f(H)` 随 `H` 增大而单调不增，所以可以直接二分答案。但树高上限只有 $4 \times 10^5$，用值域统计可以做到 $O(n + \max H)$。

**关键转换**：一棵高 `x` 的树，能被所有 `H ≤ x` 的锯片高度砍到。也就是说，每棵树都对值域区间 `[1, x]` 贡献一次覆盖。

> [!important] 单点还是区间，取决于把树放在哪根轴上
> 在**下标轴**上，一棵树只是 `cnt[h] += 1` 的单点自增；在**值域轴**上，同一棵树是 `[1, x]` 上的一次区间加。P1873 问的是「有多少棵树覆盖了这个锯片高度」，所以值域轴的区间视角更自然，恰好交给差分。

于是对每棵树做 `d[1] += 1; d[x + 1] -= 1`，前缀和还原后得到的 `cover[H]` 就是「高度不小于 `H` 的树数」，也就是下标轴上需要求后缀和的那个数组：

```cpp
// d 建在值域上，数组需开到 maxH + 2。
for (int i = 0; i < n; ++i) {
    d[1] += 1;
    d[x[i] + 1] -= 1;              // 覆盖区间 [1, x[i]]
}
for (int H = 1; H <= maxH; ++H)
    cover[H] = cover[H - 1] + d[H]; // 差分还原 == 高度 ≥ H 的树数
```

`f` 的递推是 `f(H) = f(H + 1) + cover[H + 1]`：锯片从 `H + 1` 降到 `H`，高度不小于 `H + 1` 的每棵树都多让出 1 米。从 `maxH` 向下扫，第一次 `f(H) ≥ M` 的 `H` 就是答案。

```cpp
long long wood = 0;                  // f(maxH) = 0
int ans = 0;
for (int H = maxH; H >= 0; --H) {    // 必须扫到 0
    if (wood >= M) { ans = H; break; }
    wood += cover[H];
}
```

> [!warning] 循环边界必须包含 H = 0
> 锯片高度可以是 0（整排树全砍）。若写成 `for (int H = maxH; H > 0; --H)`，答案是 0 时循环不会命中，会输出初始值。反例：`h = {2, 1}`、`M = 2`，此时 `f(0) = 3`、`f(1) = 1`，答案为 0。

复杂度 $O(n + \max H)$。若改用二分答案，每次 check 需要重扫一遍树高，为 $O(n \log \max H)$；$n = 10^6$ 时两者都能过，但值域法少一个 $\log$，且不依赖对单调性的手工论证。

### 另一种等价写法：点计数 + 后缀和

也可以先在下标轴上点计数，再求后缀和，结果与上一节的 `cover` 数组完全相同：

```cpp
for (int i = 0; i < n; ++i) ++cnt[x[i]];       // 点计数
for (int H = maxH; H >= 1; --H)                 // 后缀和
    cover[H] = cover[H + 1] + cnt[H];
```

`[1, x]` 的差分前缀和恒等于「高度 ≥ H 的计数」。两种写法只是同一件事的两个方向：**一次区间加 + 前缀和**，等价于**一次点计数 + 后缀和**。求「不小于 `H`」时，用哪种取决于你手上先有的是区间还是点。

### 为什么两种写法必然得到同一个数组

因为它们是同一个二重求和换了求和顺序。记 `[P]` 为指示函数，则

$$
\text{cover}[H] = \sum_{i=1}^{n} [x_i \ge H]
= \sum_{i=1}^{n} \sum_{t \ge H} [x_i = t]
= \sum_{t \ge H} \sum_{i=1}^{n} [x_i = t]
= \sum_{t \ge H} \text{cnt}[t]
$$

最左边是「逐棵树判断能不能砍到」，最右边是「先统计频数再累加」。换序也说明了方向：题目问「不小于 `H`」，在值域轴上对应右半段区间 `[H, maxH]`，所以累加方向朝右。

差分的解释是同一件事的另一种写法：`[x_i \ge H]` 作为 `H` 的函数是一条从 1 到 `x_i` 全为 1 的阶梯，其离散导数只在 `1` 处为 `+1`、`x_i + 1` 处为 `-1`，就是上面那段 `d` 更新。由于**求导与对 `i` 求和可交换**，「`n` 条阶梯各自求导后相加再积分」与「先合并成频数再累积」必然一致。

再换一个角度，`cover[H]` 本身是排序位置信息：

```cpp
cover[H] = n - lower_bound(sorted_x, H);   // 不小于 H 的元素个数
```

所以后缀和本质上是**把排序结果烘焙成数组**，用 $O(\max H)$ 空间换掉每次查询的 $O(\log n)$ 二分。因此选择取决于值域上界：

| 条件 | 方案 | 复杂度 |
| --- | --- | --- |
| 值域小（$\le 10^6$） | 开数组计数，前缀和或后缀和 | $O(n + V)$，查询 $O(1)$ |
| 值域大、点数少 | 排序 + `lower_bound` | $O(n \log n)$，查询 $O(\log n)$ |
| 输入本身是区间 | 只能用差分 | $O(n + V)$ |

> [!note] 先看值域上界
> 值域到 $10^9$ 时数组开不下，但排序后二分完全够用；只有值域小到能开数组时，前缀和或差分才是更优选择。

## 六、常见错误

| 错误 | 后果与修正 |
| --- | --- |
| 区间和写成 `pre[l] - pre[l - 1]` | 结果只是 `a[l]`，应为 `pre[r] - pre[l - 1]` |
| 差分数组只开 `n + 1` | 修改 `[l, n]` 时写入 `d[n + 1]` 越界，需开到 `n + 2` |
| 区间抵消写成 `d[r] -= x` | 区间右端点提前一位，应为 `d[r + 1] -= x` |
| 还原时漏掉 `a[0] = 0` | 差分前缀和失去初值，整段结果偏移 |
| 修改后仍读取原数组 | 差分不修改原数组，必须重新前缀和才能看到效果 |
| 前缀和数组用 `int` | 区间和容易溢出，按数据范围改用 `long long` |
| 元素可能为负时直接用 `%` | 余数落在 `(-k, k)`，需规整到 `[0, k)` |
| 统计 k 倍区间时漏计 `pre[0]` | 漏掉从下标 1 开始的区间，应先令 `cnt[0] = 1` |
| 二维前缀和容斥项符号写错 | 减去两个矩形后重叠部分被减两次，需要加回 `sum[x1-1][y1-1]` |
| 值域差分忘记写 `d[x + 1] -= 1` | 覆盖区间不闭合，所有高度都被算作有树 |
| 值域扫描的循环写成 `H > 0` | 答案可能是 0，此时不会命中，输出未初始化的值 |
| 值域扫描的初值取错 | 应从 `f(maxH) = 0` 出发向下累加，否则整体偏移 |

## 总结

前缀和回答「某段区间有多少」，差分回答「某段区间变了多少」。使用时先确认下标约定，再确认查询与修改的出现顺序：**范围查询用前缀和，批量区间修改用差分；交替出现时两者都不够用，需要树状数组或线段树。**

当题目关心的不是下标区间而是数值分布时，把同一套操作搬到值域轴上：**每棵树对「哪些取值能取到它」是一次区间加，所以差分同样成立**；一次区间加 + 前缀和，等价于一次点计数 + 后缀和。
